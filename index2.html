Квадрат теңдеу

ax2 + bx + c = 0, мұндағы a ≠ 0

1. Дискриминант

D = b2 − 4ac

D > 0 — екі түбірі бар
D = 0 — бір түбірі бар
D < 0 — нақты түбірі бар жоқ

2. Түбірлер формуласы

x1 = (−b + D1/2) / 2a
x2 = (−b − D1/2) / 2a

Мысал: x2 − 5x + 6 = 0

D = (−5)2 − 4 · 1 · 6 = 25 − 24 = 1
x1 = (5 + 1) / 2 = 3
x2 = (5 − 1) / 2 = 2

Виет теоремасы бойынша тексеру: x1 + x2 = 5, x1 · x2 = 6
